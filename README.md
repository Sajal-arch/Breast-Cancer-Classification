# Breast Cancer Classification 🎗️

## Project Overview
This project uses Machine Learning to classify breast cancer tumors as Malignant (M) or Benign (B) based on medical diagnostic features.

The goal is to build a classification model that can support analysis of breast cancer data.

## Objectives
- Analyze breast cancer dataset.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Train Machine Learning classification models.
- Evaluate model performance.
- Deploy the model using Streamlit.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Jupyter Notebook

## Machine Learning Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Selection
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Model Deployment

## Project Files
- `app.py` – Streamlit web application.
- Trained model (`.pkl`) – Saved Machine Learning model.
- `requirements.txt` – Required Python libraries.
- Jupyter Notebook – Project development and analysis.

## How to Run the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## Project Outcome
Developed a Machine Learning classification application to predict whether a tumor is benign or malignant based on input features.

**Note:** This project is for educational purposes and is not a substitute for professional medical diagnosis.
